One simulation system still has one experimental label.

Thousands of simulation frames can describe one protein–ligand system, but they do not create thousands of independent experimental outcomes. I built replica-aware features and grouped evaluation so frames from the same system stay together. On the current N31 panel, the strongest result did not separate reliably from the comparison models, so no model was selected. The useful output is the evaluation record: which systems were held out together, which metric was measured, and where the uncertainty remains.
