# Dynamics Atlas — 12-second micro-film

## Story thesis

An Agent may suggest a source, but registered tools and six deterministic gates
decide whether two molecular datasets can enter the same scientific route.

Suggested voice-over:

> Dynamics Atlas lets an Agent suggest a locator, then uses registered tools and
> six deterministic gates to return an EvidenceBundle or a structured stop.
