# EvidenceOps · Omni Flash global lock

这份锁定规范已经完整写入每一个 Shot 的提示词；在 Google Flow 中复制单个 Shot 的完整代码块即可，不需要再拼接本文件。

## 输入方式

- 模型：`Gemini Omni Flash`
- 模式：`Video → Frames`
- 每次只把匹配的 `SHOT-XXX.png` 上传为 `Add start frame`
- 比例：`16:9`
- 输出数量：第一次只生成 `1`
- 时长：严格使用每条提示词开头声明的 `4 秒`
- 不要把三张关键帧同时作为 Ingredients；它们是三个连续镜头，不是待混合的视觉素材

## 全局视觉锁定

- 参考图是严格首帧，不重新设计构图，不替换物体，不改变物体数量、相机角度、材质、色板、光线和文字载体。
- 保持同一套博物馆展陈级的编辑微缩模型：暖象牙纸纤维、碳黑工作台、氧化黄铜导轨与铰链、克制的赭黄色信号、柔和侧向掠射光、真实接触阴影、浅景深。
- 运动必须来自参考图中已经存在且物理可动的纸张、导轨、滑块、指示器、铰链、抽屉、手和铅笔；禁止凭空新增装置。
- 每段只有一个连续运镜。纸层之间允许真实视差和一次有来源的拉焦，禁止剪切、绕拍、第二次运镜和突然变焦。

## 全局文字锁定

- Omni Flash 不负责生成、更正或重排文字，只允许让承载文字的实体随其物理载体移动。
- 保持每个字符的拼写、大小写、空格、行数、字形、字号、颜色、位置、透视和纸质载体完全不变。
- 禁止闪烁漂移乱码数字跳变、镜像、消失、复制、增删字符、文字换行、载体互换和新增可读文字。
- 纸张正文继续保持不可读的中性行纹理，不得生成论文标题、作者、DOI、期刊、机构、日期、指标或科学结论。
- 不要旁白字幕、字幕条、浮动 UI、标志或水印。

## 音频边界

- 模型只生成无声画面，不生成对白、旁白、音乐或合成音频。
- 每条提示词末尾给出的音效均为后期制作建议，供剪辑时添加。
