How I work

Three choices carry from one project to the next.

The data changes, but the same questions return: what may the model change, what must be recorded after a failure, and what counts as an independent test item?

Model authority

Keep the model’s job narrow.

A model may retrieve, extract, draft, or suggest. Permissions, approval, source checks, and scientific vetoes stay in regular code or with a reviewer.

Failure state

Leave a record when work stops.

Invalid output, provider failure, routing decisions, and review state remain inspectable so a run can be diagnosed or resumed.

Evaluation unit

Count the independent unit.

A document, order, ligand group, or protein–ligand system should not be multiplied into extra evidence by repeated passages, requests, or frames.
