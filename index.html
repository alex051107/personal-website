01

Public MVP + controlled local prototype · Jun 2026—Present

EvidenceOps

Traceable evidence from retrieval to review.

Bounded MVP

For researchers and technical reviewers who need to carry public scientific evidence into a report, EvidenceOps keeps the source version, passage locator, assay context, and claim attached through retrieval and review.

What I built

  • Versioned source records, citation-aware chunks, and lexical/dense retrieval combined with reciprocal-rank fusion.
  • Structured extraction for values, units, measurement types, assay conditions, evidence spans, and citations.
  • Deterministic span, unit, risk, and unsupported-content checks before a candidate answer can move to review.

Engineering decision

Retrieval relevance is not treated as claim support. When the cited span or measurement context is missing, the workflow returns an explicit unsupported state instead of filling the gap from model memory.

Recorded check

70 / 70

A frozen synthetic contract covered 20 retrieval cases and 50 extraction or validation cases.

Current scope

Public or synthetic inputs only. This supports a local portfolio system—not a production service, customer deployment, or scientific-accuracy claim.

02

Synthetic workflow · Feb 2026—Present

CarePlan

A recoverable drafting workflow with pharmacist-owned approval.

Local prototype

A recoverable pharmacy-order workflow that keeps deterministic hard stops, queued model drafting, independent output validation, and pharmacist-owned approval in separate states.

What I built

  • A versioned state machine for submit, validate, queue, draft, review, reject, approve, and reopen actions.
  • Idempotent submission, role-based approval, optimistic review versions, audit receipts, and bounded retry after provider failure.
  • A typed drafting boundary whose output is validated before it can enter the review queue.

Engineering decision

The LLM has no direct edge to APPROVED. Required fields, critical conflicts, permissions, and state transitions stay in deterministic server-side rules.

Recorded acceptance

200 / 200

Authorization and state probes passed. In 120 synthetic cases, 50 stopped at rule checks and 70 reached human review; repeated same-key requests retained one plan.

Current scope

Synthetic portfolio workflow only. No real patient data, clinical recommendation, autonomous approval, or production use.

03

Research-collaboration prototype · Jun 2026—Present

Dynamics Atlas

Governed analysis across heterogeneous molecular-dynamics evidence.

Fail-closed harness

A scientific-task harness for NMR ensembles, MD trajectories, ATLAS, and mdCATH. It checks identity, mapping, condition, representation, time semantics, and claim ceiling before any analysis route is allowed to run.

What I built

  • Typed TaskPackets, allowlisted adapters, source-hash binding, DecisionTraces, EvidenceBundles, and RunReceipts.
  • Representation-specific routes that share intake and provenance without flattening non-equivalent scientific data into one feature table.
  • A bounded Agent role for proposing evidence locators and missing prerequisites, with deterministic code retaining execution and veto authority.

Engineering decision

On six exposed development fixtures, deterministic execution passed 6/6 while both Agent paths passed 0/6. I narrowed the Agent instead of presenting tool use as effectiveness.

Recorded replay

13 · 24 · 42

13/13 harness tests, 24/24 machine validations, and 42/42 HSP90 output replays passed in the recorded implementation.

Current scope

Demonstrates workflow and fail-closed behavior—not Agent effectiveness, scientific accuracy, held-out generalization, or arbitrary-data automation.

04

UNC Miao Lab research · Jun 2025—Present

HSP90 / LiGaMD

Replica-aware trajectory features for grouped pKoff evaluation.

Public toolkit

A reproducible route from three enhanced-sampling replicas to trajectory measurements and experimental-pKoff baselines, designed to prevent correlated frames or repeated ligands from inflating model evidence.

What I built

  • Geometry-defined, sustained exit detection with recapture handling instead of treating one distance spike as dissociation.
  • Replica-aware sampling of real saved frames, then 20 static and 10 dynamic features aggregated to the system level.
  • Exact-ligand-group holdouts and fold-local preprocessing so the same ligand cannot quietly appear in both train and test.

Engineering decision

The best point estimate was not promoted. Its paired bootstrap interval against the grouped baseline crossed zero, so no feature representation or model is presented as selected.

Frozen registry

N31 / 27 groups

The current registry contains 31 systems and 27 exact-ligand groups. The lowest group-equal MAE was 0.8182; uncertainty did not support model selection.

Current scope

The label is assay-derived experimental pKoff—not physical koff inferred from biased simulation time. No unseen-family generalization or final model is claimed.

Engineering approach

Systems designed for traceability, recovery, and review.

I separate model-generated proposals from executable state, deterministic validation, and human decisions so failures remain diagnosable and work can resume safely.

01

Bound the model.

Give it typed inputs, allowlisted tools, and no hidden promotion path.

02

Persist the failure.

Timeouts, malformed outputs, stale reviews, and stop decisions become inspectable state.

03

Split by the real unit.

Users, documents, ligands, systems, and trajectories are not interchangeable samples.

04

Name the ceiling.

A passing test proves its scoped contract—not production readiness, impact, or generalization.

Human ownership

AI-assisted coding is part of my workflow. I own the problem framing, architecture choices, validation gates, failure review, and interpretation of results.
